# Docket for Mac — issue tracker

Report a problem with Docket in [Issues](https://github.com/r0llingclouds/docket-support/issues/new).
Include the Docket version and build, your macOS version, the steps to reproduce,
what happened and what you expected. Docket's **Report a Problem…** command starts
a draft with app and system metadata; you can review it before posting.

This repository contains support information and issue templates. The application
source code is maintained separately. Creating this tracker does not announce a
release; downloads will be available at [rollingclouds.dev/docket](https://rollingclouds.dev/docket/)
after publication is approved.

Issues are public. Remove personal task text, account details and other private
information from screenshots or logs. Do not attach your task database.
